# HFG 0.1.10 发布说明

## 重点变更

- Gateway 证书清单与生命周期管理：系统管理新增「Gateway 证书」版块，逐张列出证书的 Gateway 标识、服务组、使用状态（在用 / 已换发 / 已过期 / 未使用）、使用节点名称与 IP、有效期和指纹；支持下载已签发证书（`gateway.crt` + `ca.crt` + 说明，不含私钥）、按节点重新生成、删除未在用证书。操作按钮统一放在版块标题右侧，勾选行后批量执行。
- 证书共用防护与上线校验：Gateway 上线时校验客户端证书 CN 必须等于配置的 Gateway 标识，且证书在该服务组处于 ACTIVE、仍在有效期内；节点表记录实际上报的证书指纹，同一标识 + 同一张证书在心跳窗口内由不同主机名上报会被拒绝，避免一张证书被多台主机共用。
- 在用证书保护：正在被在线节点使用的证书不允许删除，需先停止该节点或先换发新证书，防止把运行中的 Gateway 锁在控制面之外。
- 登录交互修复：未认证请求统一返回 401 JSON，且不再发送 `WWW-Authenticate` 挑战头，管理页面不会再弹出浏览器原生账号密码框；会话失效时前端自动回到登录页。
- 服务组操作修复：新建服务组接口返回创建结果，此前空响应体会让页面误报失败、弹窗不关闭、再次提交报重复；删除服务组的关联校验只看本组用户、这些用户拥有的目录和本组在线 Gateway，不再把同一 HDFS 连接上其它服务组的目录误判为关联。
- 页面布局调整：页面标题与描述同行显示、描述按可用宽度缩略；筛选与操作按钮下移到标题下方，宽度不足时自动换行；系统管理各版块的操作按钮放入版块标题右侧并右对齐；页面级下拉菜单比选择框略宽。
- 数据库：新增 V9 迁移（`gateway_certificate.certificate_pem`、`gateway_node.certificate_fingerprint` 及相关索引）。

## 升级说明

1. 升级前备份管理库、日志库、`/etc/hfg` 和 HDFS 配置包目录。
2. V9 只新增列与索引，不删除既有数据；历史上已签发证书的正文无法回溯补录，这类证书在清单中显示为不可下载，需要凭据时用「重新生成」签发新证书（旧证书继续有效，可平滑替换）。
3. Manager 与 Gateway 建议在同一维护窗口滚动升级：先升级 Manager，再升级 Standby Gateway、切换 VIP，最后升级另一台 Gateway。
4. 升级后确认「Gateway 证书」中在用证书与节点指纹一致；节点指纹在升级后的首次心跳后写入，稍后刷新即可看到。

## 介质

- `hfg-0.1.10-linux-x86_64-native.tar.gz`：Native JAR、Java 17 运行说明、systemd、Keepalived、Prometheus 配置和文档。
- `hfg-0.1.10-linux-x86_64-docker.tar.gz`：linux/amd64 Manager/Gateway 镜像、Compose、Keepalived、Prometheus 配置和文档。
- `SHA256SUMS`：两个独立压缩包的 SHA-256。
