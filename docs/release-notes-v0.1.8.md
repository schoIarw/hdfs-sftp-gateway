# HFG 0.1.8 发布说明

## 主要变更

- 流控与配额 P0：Manager 可按周期剩余额度部分授予字节租约，修复小于 64 MiB 或窗口尾部额度被提前拒绝的问题。
- 断点续传：成功上传按暂存文件已有字节与本次新增字节之和结算配额并记录完整文件大小，避免通过续传绕过周期额度。
- 失败清理：初始配额预留失败时释放 Gateway 并发许可和已取得的租约；打开存储句柄后限流初始化失败时关闭句柄。
- 自动发布：用户、SSH 公钥、目录、权限、流控策略和服务组变更后进入持久化待发布队列，默认在 2 秒内合并生成签名快照。
- 一致性检查：Manager 默认每 5 分钟检查全部启用服务组；自动发布失败默认 30 秒后重试，配置未变化时不增加快照版本。
- 人工强推：管理页面保留“强制发布”，用于主动重推和故障恢复；即使配置内容不变也会生成更高版本。
- 数据库兼容：PostgreSQL 17 与 MySQL 8 同步增加 V7 迁移；修复 MySQL `CHAR(36)` 快照主键写入兼容问题。

## 升级说明

1. 升级前备份管理数据库、日志数据库、`/etc/hfg` 和 `/var/lib/hfg`。
2. 先升级 Manager。启动时 Flyway 会自动执行 V7 迁移，增加配置源摘要和持久化发布队列表。
3. 确认 Manager 健康检查、数据库迁移和管理页面正常后，再逐台滚动升级 Gateway。
4. 升级后修改一项测试用户策略，确认默认 2 秒内产生新快照且 Gateway 心跳版本随之更新。
5. 点击“强制发布”，确认即使内容未变化仍生成更高版本并推送。

Native 与 Docker 仍为两个独立介质，不提供混合压缩包。完整安装、升级和验收步骤见 [编译介质部署手册](package-deployment.md)。
