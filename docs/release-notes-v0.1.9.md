# HFG 0.1.9 发布说明

## 重点变更

- 多用户认证：增加 FTP、SFTP 双用户独立认证回归测试和 Manager 双用户签名快照集成测试，验证第二个及后续用户不会复用首个用户的认证状态；SFTP 同时按用户执行连接并发限制并在会话关闭时释放许可。
- 目录与权限合并：移除独立权限管理接口和页面。每条目录只归属一个用户，权限只允许只读或读写；不同用户可以分别拥有相同虚拟路径（包括 `/`），快照不会下发其他用户目录。
- 目录配额：文件/目录项数（HDFS namespace quota）和空间配额都在单个目录上配置、展示和执行，不再提供用户周期文件数或周期字节数额度。
- 流控收敛：策略只保留上传速率、下载速率和最大连接数，移除突发量、传输并发、周期窗口及额度租约 RPC。
- 业务指标分层：总览只展示不带用户维度的总体指标；用户看板默认按颜色展示所有用户的独立上传/下载曲线，并支持单用户筛选。流控看板查询 `logs` 日分区中的实际业务数据。
- 管理界面：用户、目录、流控、HDFS 和服务组列表改为复选框选择并在页面顶部统一操作；用户和目录支持筛选。系统管理新增“监控告警”面板显示开关。
- 数据库兼容：V8 迁移同时覆盖 PostgreSQL 与 MySQL，移除旧授权表、周期额度表及废弃流控字段，并补齐 UUID/CHAR 查询适配。

## 升级说明

1. 升级前必须备份管理库、日志库、`/etc/hfg` 和 HDFS 配置包目录。
2. V8 会把每个旧目录最早的一条授权迁移为该目录的唯一归属用户；一个目录若原来授权给多个用户，其余授权不会保留。升级前应先确认实际目录归属，升级后在目录管理中逐项复核。
3. 没有旧授权的目录会显示“待分配”，不会进入任何用户快照；编辑目录并选择归属用户后自动生效。
4. V8 会删除 `directory_grant`、`usage_window`、`quota_reservation` 以及废弃流控列，此迁移不可通过简单回滚恢复旧模型。
5. Manager 与 Gateway 建议在同一维护窗口滚动升级。先升级 Manager 并完成迁移，再升级 Standby Gateway、切换 VIP，最后升级另一台 Gateway。

## 介质

- `hfg-0.1.9-linux-x86_64-native.tar.gz`：Native JAR、Java 17 运行说明、systemd、Keepalived、Prometheus 配置和文档。
- `hfg-0.1.9-linux-x86_64-docker.tar.gz`：linux/amd64 Manager/Gateway 镜像、Compose、Keepalived、Prometheus 配置和文档。
- `SHA256SUMS`：两个独立压缩包的 SHA-256。
- `bom.json`：CycloneDX SBOM。

Native 与 Docker 介质保持分离，不再提供包含两者的整体压缩包。
